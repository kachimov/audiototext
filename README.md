# AudioToText 🎙️

Автономная программа для высокоточного преобразования речи из видео- и аудиозаписей в текст, субтитры и монтажные таймкоды с поддержкой аппаратного ускорения на видеокартах NVIDIA (CUDA).

---

## 🚀 Быстрый старт (Инструкция по использованию)

1. **Скачайте лаунчер**: перейдите в раздел [Releases](../../releases) и скачайте файл **`AudioToText.exe`** (компактный файл около ~25 МБ).
2. **Создайте папку**: создайте на компьютере любую пустую папку (например, `AudioToText`) и поместите туда скачанный `AudioToText.exe`.
3. **Первый запуск**: запустите `AudioToText.exe`. 
   * При первом запуске лаунчер автоматически скачает необходимые компоненты (ядро программы и библиотеки нейросети). Объём загрузки составляет **около ~4 ГБ** (зависит от скорости вашего интернета).
   * После завершения распаковки программа запустится автоматически.
4. **Загрузка моделей**: для работы программы требуются файлы весов моделей Whisper. Вы можете выбрать любую модель в зависимости от мощности вашего ПК и требований к точности:

| Название модели | Размер файла | Требования к VRAM / RAM | Описание и рекомендации |
| :--- | :--- | :--- | :--- |
| **Tiny** (`tiny.pt`) | ~75 МБ | ~1 ГБ | Сверхбыстрая модель для базовых тестов с минимальным качеством. |
| **Base** (`base.pt`) | ~142 МБ | ~1.5 ГБ | Быстрая модель для простых задач и чистого звука. |
| **Small** (`small.pt`) | ~483 МБ | ~2 ГБ | Отличный баланс между скоростью работы и качеством. |
| **Medium** (`medium.pt`) | ~1.5 ГБ | ~5 ГБ | Высокая точность распознавания терминов и сложной речи. |
| **Large v3** (`large-v3.pt`) | ~2.9 ГБ | ~10 ГБ | Флагманская модель с максимальной точностью (рекомендуется для русского языка). |

   * *Если выбранная модель отсутствует на диске, программа покажет диалоговое окно с прямой официальной ссылкой на скачивание.*
   * *Скачайте нужный файл весов и положите его в папку `models/` рядом с программой.*

## ⚙️ Подробные функции и возможности программы

* **Поддержка 23+ медиаформатов**: обработка видео (MP4, MKV, AVI, MOV, WMV, FLV, WEBM и др.) и аудио (MP3, WAV, FLAC, M4A, OGG и др.) без необходимости предварительной ручной конвертации через сторонние конвертеры.
* **7 форматов экспорта результатов**:
  * **SRT**: универсальный стандарт субтитров для плееров и видеохостингов.
  * **VTT**: современный формат веб-субтитров для браузеров и онлайн-платформ.
  * **TXT**: чистый сплошной текст стенограммы для чтения и рерайта.
  * **ASS**: форматированные субтитры с поддержкой стилей и позиционирования.
  * **TSV**: табличные данные (время начала, окончания и текст) для анализа в Excel или Google Таблицах.
  * **JSON**: полный машиночитаемый дамп структуры сегментов и вероятностей.
  * **JSON Frames ⭐ (Авторская разработка)**: уникальный формат, созданный специально для глубокой интеграции с **DaVinci Resolve**. Для видеофайлов программа автоматически рассчитывает номера кадров (`start_frame` / `end_frame` на основе точного FPS видеопотока), а для аудиозаписей формирует прецизионную миллисекундную разметку.
* **Пословные таймкоды (Word Timestamps)**: детализация таймингов до каждого отдельного слова для продвинутого монтажа.
* **Silero VAD (фильтрация тишины)**: программное подавление пауз без голоса для предотвращения артефактов на тихих участках.
* **Подсказка для модели (Initial Prompt)**: возможность задать список специфических терминов, имён собственных или аббревиатур для повышения точности.

## 🌍 Поддерживаемые языки

Модель Whisper поддерживает автоматическое определение языка или принудительный выбор из более чем 90 языков мира. Наиболее популярные и стабильно используемые в работе:
* **Русский**, **Английский**, **Украинский**, **Белорусский**
* **Немецкий**, **Французский**, **Испанский**, **Итальянский**, **Португальский**
* **Китайский**, **Японский**, **Корейский**, **Арабский**, **Турецкий**, **Польский** и др.

## 🛠️ Как работать с программой

1. **Добавление файлов**: перетащите нужные видео или аудиофайлы в верхнюю область программы или нажмите «Выбрать файлы».
2. **Настройки**: в правой панели выберите модель, устройство вычисления (GPU/CPU) и желаемый формат экспорта.
3. **Транскрипция**: нажмите кнопку **«▶ Начать транскрипцию»** и дождитесь завершения процесса.
4. **Результаты**: по окончании работы программа предложит открыть папку с готовыми файлами экспорта.
