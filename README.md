# AudioToText 🎙️

Автономная программа для высокоточного преобразования речи из видео- и аудиозаписей в текст, субтитры и монтажные таймкоды с поддержкой аппаратного ускорения на видеокартах NVIDIA (CUDA).

---

## 🚀 Быстрый старт (Инструкция по использованию)

1. **Скачайте лаунчер**: перейдите в раздел [Releases](../../releases) и скачайте файл **`AudioToText.exe`** (компактный файл около ~25 МБ).
2. **Создайте папку**: создайте на компьютере любую пустую папку (например, `AudioToText`) и поместите туда скачанный `AudioToText.exe`.
3. **Первый запуск**: запустите `AudioToText.exe`. 
   * При первом запуске лаунчер автоматически скачает необходимые компоненты (ядро программы и библиотеки нейросети). Объём загрузки составляет **около ~4 ГБ** (зависит от скорости вашего интернета).
   * После завершения распаковки программа запустится автоматически.
4. **Загрузка моделей**: для работы программы требуются файлы весов моделей Whisper. Вы можете выбрать любую модель в зависимости от мощности вашего ПК и требований к точности:

| Название модели | Размер файла | Требования к VRAM / RAM | Описание и рекомендации |
| :--- | :--- | :--- | :--- |
| **Tiny** (`tiny.pt`) | ~75 МБ[cite: 1] | ~1 ГБ | Сверхбыстрая модель для базовых тестов с минимальным качеством[cite: 1]. |
| **Base** (`base.pt`) | ~142 МБ[cite: 1] | ~1.5 ГБ | Быстрая модель для простых задач и чистого звука[cite: 1]. |
| **Small** (`small.pt`) | ~483 МБ[cite: 1] | ~2 ГБ | Отличный баланс между скоростью работы и качеством[cite: 1]. |
| **Medium** (`medium.pt`) | ~1.5 ГБ[cite: 1] | ~5 ГБ | Высокая точность распознавания терминов и сложной речи[cite: 1]. |
| **Large v3** (`large-v3.pt`) | ~2.9 ГБ[cite: 1] | ~10 ГБ | Флагманская модель с максимальной точностью (рекомендуется для русского языка)[cite: 1]. |

   * *Если выбранная модель отсутствует на диске, программа покажет диалоговое окно с прямой официальной ссылкой на скачивание[cite: 1].*
   * *Скачайте нужный файл весов и положите его в папку `models/` рядом с программой[cite: 1].*

## ⚙️ Подробные функции и возможности программы

* **Поддержка 23+ медиаформатов**: обработка видео (MP4, MKV, AVI, MOV, WMV, FLV, WEBM и др.) и аудио (MP3, WAV, FLAC, M4A, OGG и др.) без необходимости предварительной ручной конвертации через сторонние конвертеры.
* **7 форматов экспорта результатов**:
  * **SRT**: универсальный стандарт субтитров для плееров и видеохостингов[cite: 2].
  * **VTT**: современный формат веб-субтитров для браузеров и онлайн-платформ[cite: 2].
  * **TXT**: чистый сплошной текст стенограммы для чтения и рерайта[cite: 2].
  * **ASS**: форматированные субтитры с поддержкой стилей и позиционирования[cite: 2].
  * **TSV**: табличные данные (время начала, окончания и текст) для анализа в Excel или Google Таблицах[cite: 2].
  * **JSON**: полный машиночитаемый дамп структуры сегментов и вероятностей[cite: 2].
  * **JSON Frames**: специальный формат для **DaVinci Resolve** (для видео рассчитывает кадры по точному FPS, для аудио — миллисекундные таймкоды)[cite: 2].
* **Пословные таймкоды (Word Timestamps)**: детализация таймингов до каждого отдельного слова для продвинутого монтажа[cite: 2].
* **Silero VAD (фильтрация тишины)**: программное подавление пауз без голоса для предотвращения артефактов на тихих участках[cite: 2].
* **Подсказка для модели (Initial Prompt)**: возможность задать список специфических терминов, имён собственных или аббревиатур для повышения точности[cite: 2].

## 🌍 Поддерживаемые языки

Модель Whisper поддерживает автоматическое определение языка или принудительный выбор из более чем 90 языков мира. Наиболее популярные и стабильно используемые в работе:
* **Русский**, **Английский**, **Украинский**, **Белорусский**
* **Немецкий**, **Французский**, **Испанский**, **Итальянский**, **Португальский**
* **Китайский**, **Японский**, **Корейский**, **Арабский**, **Турецкий**, **Польский** и др.

## 🛠️ Как работать с программой

1. **Добавление файлов**: перетащите нужные видео или аудиофайлы в верхнюю область программы или нажмите «Выбрать файлы»[cite: 1].
2. **Настройки**: в правой панели выберите модель, устройство вычисления (GPU/CPU) и желаемый формат экспорта[cite: 1].
3. **Транскрипция**: нажмите кнопку **«▶ Начать транскрипцию»** и дождитесь завершения процесса[cite: 1].
4. **Результаты**: по окончании работы программа предложит открыть папку с готовыми файлами экспорта[cite: 1].
