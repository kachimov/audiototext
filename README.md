# AudioToText 🎙️

Автономная программа для высокоточного преобразования речи из видео- и аудиозаписей в текст, субтитры и монтажные таймкоды с поддержкой аппаратного ускорения на видеокартах NVIDIA (CUDA).

## 💻 Системные требования

* **Операционная система**: **Windows 10** или **Windows 11** (только 64-bit).
* **Видеокарта (GPU)**: 
  * **NVIDIA** (серии GTX 10xx, RTX 20xx, 30xx, 40xx и новее) с поддержкой CUDA для быстрого аппаратного ускорения.
  * **AMD (Radeon) и Intel Arc**: аппаратное ускорение CUDA **не поддерживается архитектурой**. На ПК с видеокартами AMD программа работает в режиме **CPU (на центральном процессоре)**.
* **Системные компоненты**: установленный пакет [Microsoft Visual C++ Redistributable 2015–2022 (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe) (необходим для работы скомпилированных бинарных модулей Python и PyTorch).

## ⚙️ Подробные функции и возможности программы

* **Поддержка 23+ медиаформатов**: обработка видео (MP4, MKV, AVI, MOV, WMV, FLV, WEBM и др.) и аудио (MP3, WAV, FLAC, M4A, OGG и др.) без предварительной ручной конвертации.
* **7 форматов экспорта результатов**:
  * **SRT**: базовый стандарт субтитров для плееров и видеохостингов.
  * **VTT**: формат веб-субтитров для браузеров и онлайн-платформ.
  * **TXT**: сплошной текст стенограммы для чтения и рерайта.
  * **ASS**: субтитры с расширенным позиционированием и стилями.
  * **TSV**: табличные данные (время начала, окончания, текст) для Excel и Google Таблиц.
  * **JSON**: полный структурированный дамп сегментов и таймкодов.
  * **JSON Frames ⭐ (Авторская разработка)**: прецизионный формат для глубокой интеграции с **DaVinci Resolve**. Программа высчитывает точные номера монтажных кадров (`start_frame` / `end_frame` на базе FPS медиафайла) для расстановки маркеров на таймлайне.
* **Пословные таймкоды (Word Timestamps)**: детализация таймингов до каждого слова для динамических субтитров.
* **Silero VAD**: программная фильтрация тишины и пауз между фразами.
* **Подсказка для модели (Initial Prompt)**: словарь контекста, редких терминов и имён собственных.

## ❓ Возможные проблемы и их решение (Troubleshooting)

#### Сообщайте о багах, предлагайте идеи доработок или программ: https://kachimov.ru/apphelp

* **Долгая пауза на Splash-экране / первый запуск (15–40 секунд)**:
  * **Причина**: при первом старте библиотеки PyTorch и CUDA инициализируют видеокарту и компилируют кэш шейдеров. Одновременно антивирус **Защитник Windows (Windows Defender)** проверяет тысячи распакованных бинарных библиотек в фоновом режиме.
  * **Решение**: не закрывайте окно принудительно, программа не зависла. Все последующие запуски будут происходить штатно за 2–4 секунды.
* **Работа на видеокартах AMD Radeon и встроенной графике**:
  * Аппаратное ускорение **CUDA работает только на картах NVIDIA**. 
  * Если у вас видеокарта AMD, в правой панели настроек программы обязательно переключите пункт **Устройство (Device)** на **CPU**. Рекомендуется использовать модели *Tiny*, *Base* или *Small* для комфортной скорости работы.
* **Лаунчер закрылся после 100%, и ничего не открылось**:
  * Убедитесь, что установлен пакет [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe). Без него системные библиотеки Python не могут загрузиться в память.
* **Предупреждение Windows SmartScreen**:
  * Так как приложение распространяется как открытый проект без платной цифровой подписи Microsoft Authenticode, нажмите **«Подробнее» (More info)** ➔ **«Выполнить в любом случае» (Run anyway)**.
